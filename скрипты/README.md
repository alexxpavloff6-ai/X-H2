# Скрипты

## xh2_usb.py — проявка RAW в камере X-H2 по USB

Скрипт для Windows. Работает со стандартным драйвером Microsoft, без Zadig и libusb.

```
pip install comtypes
python xh2_usb.py info                                    # что отдаёт камера (только чтение)
python xh2_usb.py profile DSCF0001.RAF                    # профиль проявки, построенный камерой по кадру
python xh2_usb.py convert DSCF0001.RAF out.jpg --recipe recipe_example.json --full
python xh2_usb.py convert DSCF0001.RAF out.jpg --film classic_chrome --color 2
```

Условия:
- на камере выбран «Режим подключения к ПК → USB RAW CONV./BACKUP RESTORE»;
- RAF снят этой же камерой, иначе камера откажет;
- `--full` даёт полный размер 7728×5152, без него — 3888×2592.

Безопасность. Скрипт может записать в камеру только сам RAF (в буфер проявки, не на карту), профиль D185 и команду запуска D183. Удаляет только свои временные результаты. Запись слотов C1–C7 (0xD18C–0xD1A5) заблокирована в коде.

Проверено на X-H2 с прошивкой 5.30. Рецепт `recipe_example.json` проявлен камерой, и MakerNote результата совпал с рецептом по всем полям. Карта полей профиля — в [отчёте](../полные_отчёты/Чтение_камеры_по_USB/Проявка_в_камере.md).
