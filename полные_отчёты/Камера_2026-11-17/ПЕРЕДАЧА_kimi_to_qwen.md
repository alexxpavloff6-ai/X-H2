## Камера и режим

X-H2, прошивка **5.30** (исправления LCD нет — дефект должен воспроизводиться). USB-режим **USB RAW CONV./BACKUP RESTORE** (в нём 61 свойство/20 операций, `0x500D` и `0xD201` НЕ объявлены — выдержку и DRIVE брать из блоба). Владелец меняет настройки **с отключённым кабелем**, затем подключает и пишет координатору; координатор проверяет PnP (`VID_04CB&PID_02F2 Present True`) и только потом даёт команду. Если WPD видит 0 устройств — ничего не отправлять, сразу `ask`.

## Калиброванные поля BACKUP (file offsets, проверено на реальных блобах)

| Поле | Смещение | Значения |
|---|---|---|
| SHUTTER TYPE (UI_SETP 0x827) | `0x63A` | 1 = ES, 2 = MS+ES, 3 = **EF**, (0 = MS ожидается) |
| Фактический затвор DOTLCD_SHUTTERTYPE_OUTPUT | `0x1A8` | электронный в 02B и 03 |
| DOTLCD_SHUTTERTYPE | `0x1D8` | повторяет выбор |
| DRIVE: CONTINUOUS | `0x4F8` | 0 = S, 1 = серия |
| DRIVE: DOTLCD_CONTINUOUS/2 | `0x68C/0x68D` | 0 = S, 21 = CH |
| DOTLCD_CONTMODE / DRV_MENU | `0xEC` / `0x4CD` | 0→1 при CH |
| Выдержка SHUTERSPEED_OUTPUT | `0x18C` u32LE | знаменатель×100 (1/25=2500, 1/8000=800000, 1/16000=1600000) |
| SHUTTER_SPEED_M / дисплей | `0x5B2` / `0x681` | индексы |
| IMAGE DISP (REC_VIEW) | `0x29B` | 3 = OFF, 2 = CONTINUOUS |
| Служебное | `0xC0–0xE5` (меню, `SETTING_CHKSUM` @`0xE4`), `0xF6BC` (вероятно счётчик), `0xF724` (volatile) | не учитывать |

Записи `0x4C` (сигнатура `4c 00 ?? ?? 58 01 00 00`) в BACKUP нет ни в одном снимке; кандидата на guard-флаг среди сохраняемых настроек нет (флаг — runtime/сервисная запись).
