# Проявка RAW в камере по USB

Дата: 10 ноября 2026. Камера X-H2, прошивка 5.30, режим USB RAW CONV./BACKUP RESTORE. Исходный кадр снят на слоте C1 (Classic Chrome, «Цвет +2»).

## Что отправлялось в камеру

- RAF — в буфер камеры с компьютера (вендорские операции 0x900C/0x900D), не на карту;
- профиль проявки D185 и команда запуска D183 = 0;
- удаление только своих временных результатов (0x100B).

Номер слота D18C до и после — 1. Слоты и карта не менялись. Все ответы камеры 0x2001, ошибок не было. Одна проявка занимает около 1,1 с.

## Профиль D185

До загрузки RAF камера отвечает на чтение D185 ошибкой 0x2002. После загрузки отдаёт профиль самого кадра: 625 байт, 29 полей (у rawji стандартный формат — 628 байт, у X-T30 — 605). Значения совпали со слотом C1:

| Поле | Значение | Смысл |
|-|-|-|
| 6 | 100 | DR100 |
| 8 | 11 | Classic Chrome |
| 9 | — | зерно выкл. |
| 10 | 3 | Color Chrome сильный |
| 14 | −4 | сдвиг баланса B |
| 16 / 17 | −10 / −10 | света / тени −1 |
| 18 | 20 | «Цвет» +2 |
| 20 | 0x8000 | NR −4 |
| 25 | 2 | FX Blue слабый |
| 27 | 0 | «Чёткость» 0 |

Не расшифрованы поля 0–5, 21–24, 26 и 28. Поля сжатия RAW в профиле нет.

## Серия

Базовый профиль, затем «Цвет» 0, +1, +2 по два раза, затем снова базовый: 8 проявок. Камера вернула JPEG 3888×2592. Это размер S: по fujinx значение D183 = 0 означает быструю проявку в половинном разрешении, полное — D183 = 1.

## Результаты

**Насыщенность.** C*(+2) / C*(0) = 1,0975 в обоих прогонах, C*(+1) / C*(0) = 1,045. В прошивке для «Цвет +2» множитель меняется со 128 на 141, то есть в 1,1016 раза. Ручная серия давала 1,106. Три независимых измерения сходятся в пределах 1%.

**Повторяемость.** Ни одна пара одинаковых проявок не совпала побайтно. Среднее расхождение 0,965–0,971 уровня из 255, максимум 12–13, точно совпадает около 31% пикселей. При этом средние L* и C* повторяются до четвёртого знака.

**Вывод.** Разница между одинаковыми проявками (в ручной серии 0,84 уровня) — свойство самой камеры, а не ошибка оператора: профиль отправлялся байт в байт одинаковым. Похоже, камера добавляет при проявке шум или дизеринг, а сама обработка не меняется.

## Что дальше

- Повторить серию в полном разрешении (D183 = 1) для прямого сравнения с ручной серией.
- Расшифровать оставшиеся поля профиля, меняя по одному.
- Предложить авторам fujinx поддержку X-H2: чтение слотов и проявка работают так же, как у X-M5. Только с согласия владельца.
