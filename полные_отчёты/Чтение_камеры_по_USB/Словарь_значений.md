# Единый словарь значений: меню прошивки, USB и внутренние коды

Проверка от 10 ноября 2026 года, прошивка X-H2 5.30, только чтение файла FWUP0028.DAT. Продолжение отчёта [Связь USB и прошивки](Связь_USB_и_прошивки.md).

## Главный вывод

Значения для USB прошивка не вычисляет кодом, а берёт из готовых таблиц перевода. Для каждой настройки меню есть своя таблица. Строка таблицы соответствует пункту меню, а четыре столбца — четырём представлениям одного и того же значения. Четвёртый столбец — это ровно то число, которое камера отдаёт и принимает по USB.

Проверка: все 30 значений, которые мы раньше установили опытами на камере, совпали с четвёртым столбцом. Расхождений нет. Полный словарь на 161 свойство и 1 191 значение: [Словарь_значений_USB_и_прошивки.tsv](Словарь_значений_USB_и_прошивки.tsv).

## Как устроено

- Блок I прошивки, адрес 0x01BD5AB8 (смещение 0xAD4AB8 в распакованном блоке): массив 64-разрядных указателей. Номер элемента совпадает с номером настройки UI_SETP_…
- Каждый указатель ведёт к таблице из строк по четыре 32-разрядных числа. Таблица заканчивается строкой из 0xFFFF, а 0x7FFFFFFE означает «нет значения в этом представлении».
- Номер строки — значение из словаря меню (например, UI_FILM_SIM_CLASSIC_CHROME = 14).
- Третий столбец — внутреннее значение. Его использует конвертер 0x012E67AC из прежних работ: для плёнки 14 → 13, для «Цвета» 0…8 → те же 0…8.
- Четвёртый столбец — значение протокола USB.

Две прежние находки встали на свои места:
- конвертер «Цвета» и таблица 0x0176D7B0 из [работы по MakerNote](../Последовательное_исследование/Этап_1/Цвет_в_MakerNote/Отчёт.md) — это тот же механизм, таблица для STILLCOLOR;
- таблица производительности из [исследования без камеры](../Исследование_без_камеры/Производительность/Отчёт.md) — таблица для UI_SETP_PERFORMANCE.

Внутренние имена Fujifilm расходятся с маркетинговыми: Classic Neg. в прошивке называется SUPERIA, Nostalgic Neg. — AMERICAN_NEW_COLOR, а Velvia и Astia — F2 и F1B. Привычные названия для непроверенных строк взяты по порядку кодов USB, который совпадает с общеизвестной нумерацией Fujifilm PTP. Строки F1C, BW и CHROME в X-H2 значения USB не имеют: это пункты, недоступные на этой модели.

Внутреннее 19 для SUPERIA — то самое число, которое в [исследовании FilmMode](../Проявка_0296/FilmMode/Отчёт.md) другой конвертер переводил в 0x0800, код Classic Negative в EXIF. Так замыкается цепочка «меню → внутреннее → USB → файл».

## Тон и цвет: формат «×10»

| Настройка | USB | Шаг |
|-|-|-|
| STILLCOLOR (Цвет, D008) | +40 … −40 | 10 |
| SHARPNESS (Резкость, 5015) | +40 … −40 | 10 |
| HIGHLIGHT (Светá) | +40 … −20 | 5, то есть полшага |
| SHADOW (Тени) | +40 … −20 | 5 |
| CLARITY (Чёткость) | +50 … −50 | 10 |

Это тот же формат «×10», что в профиле проявки D185.

## Шумоподавление: несмежные коды

| NR | −4 | −3 | −2 | −1 | 0 | +1 | +2 | +3 | +4 |
|-|-|-|-|-|-|-|-|-|-|
| USB D01C | 0x8000 ✓ | 0x7000 | 0x4000 | 0x3000 | 0x2000 ✓ | 0x1000 | 0x0000 | 0x6000 | 0x5000 |

Коды не идут по порядку, поэтому угадать их было бы нельзя. Наблюдавшиеся на камере 0x8000 = −4 и 0x2000 = 0 совпали.

| Настройка | Значения USB |
|-|-|
| Режим фокуса (500A) | AF-C 0x8002 ✓, AF-S 0x8001 ✓, MF 1 ✓ |
| Область AF (501C) | AUTO, то есть широкая или следящая 0x8003 ✓; одна точка 0x8001 ✓; зона 0x8002 ✓ |
| Лица (D020) | вкл. 1 ✓, выкл. 2 ✓ |
| Глаза (D024) | выкл. 1 ✓, авто 2 ✓, правый 3 ✓, левый 4 (раньше было предположением, теперь подтверждено таблицей) |
| Объекты (D1BD) | выкл. 1 ✓, животные 2 ✓, птицы 3 ✓, авто 4, мотоциклы 5, самолёты 6, поезда 7 |
| Набор AF-C (D232) | SET 1…6 → 1…6 ✓ |

Производительность (D304) раскрылась полностью. Все шесть рабочих значений проверены на камере: владелец переключал меню, компьютер только читал.

| USB | Имя в прошивке | Меню камеры (Управление питанием) | Проверено |
|-|-|-|-|
| 1 | NORMAL | Производительность: Normal | ✓ |
| 2 | ECO | Производительность: Economy | ✓ |
| 3 | BOOST_AND_LOW_LIGHT | Boost + EVF/LCD: приоритет слабого освещения | ✓ |
| 4 | BOOST_AND_RESOLUTION | Boost + EVF/LCD: приоритет разрешения | ✓ |
| 5 | BOOST_AND_FRAME | Boost + EVF: частота кадров 120P | ✓ |
| 6 | BOOST_AND_PHASE | в меню X-H2 нет, камера значение не принимает | — |
| 7 | BOOST_AND_FRAME_REDUCTION | Boost + EVF: частота кадров «240P экв.» | ✓ |

Значит, D304 одним числом кодирует пару «производительность + настройка Boost для EVF/LCD» (MENU → SET UP → POWER MANAGEMENT → EVF/LCD BOOST SETTING, [руководство X-H2](https://fujifilm-dsc.com/en/manual/x-h2/menu_setup/power_management/)). При Normal и Economy пункт Boost сохраняет выбор, но не действует. Все замеры AF «на Boost» сделаны в варианте 120P, код 5.

Попутно: пока открыто меню камеры, свойство D22E равно 3, а все прочие чтения получают ответ 0xA001 «занято». В режиме съёмки D22E = 1.

## Профиль проявки D185 и меню «Проявка RAW»

Профиль D185 соответствует меню камеры «Проявка RAW». В прошивке есть словарь UI_SETP_RAW_DEV_… и внутренняя структура из 30 параметров. Функция рядом с обработчиками USB читает каждый параметр и переводит его через те же таблицы. Имена полей нашего профиля (номер поля — как в [отчёте о проявке](Проявка_в_камере.md)):

| Поле | Наш смысл | Имя в прошивке |
|-|-|-|
| 2, 3, 4 | не влияли на результат | KIND, PXL, QTY: тип файла, размер и качество. Размер задаёт D183, поэтому сами поля по USB и не действовали |
| 10 | Color Chrome Effect | SHADOWING |
| 21 | Lens Modulation Optimizer | LEQ |
| 23, 26 | тонирование монохрома | BLACK_TONE, BLACK_TONE_RG |
| 25 | FX Blue | BLUE_EFFECT |
| 9 | зерно 1–5 | внутри раскладывается на GRAIN и GRAIN_SIZE |

Остальные поля (экспозиция, DR, плёнка, баланс белого и сдвиги, цвет, резкость, NR, света, тени, чёткость, цветовое пространство) совпали со своими настройками один в один. Порядок полей в профиле USB отличается от внутреннего: камера переставляет их при приёме. Для пунктов меню DIGITAL_TELECONV, ASPECT и HDR явного поля в профиле нет. Возможно, это необъяснённые поля 0, 1 или 28.

Коды NR в слотах (D1A1) совпадают с кодами свойства D01C из таблицы выше. Что поле NR профиля D185 использует ту же шкалу, вероятно, но опытом не проверено.

## Ограничения

- Таблицы прочитаны из файла, а не исполнены в камере. Достоверность значений USB опирается на совпадение всех 30 проверенных точек. Остальные значения — следствие того же механизма, но на камере не проверены.
- Названия режимов Boost 3, 4 и 7 по-русски даны по смыслу имён прошивки и меню камеры. Строк меню, переведённых на язык камеры, здесь нет.
- Связь внутреннего значения с EXIF установлена только для плёнок и «Цвета». Для остальных настроек это следующий шаг.
