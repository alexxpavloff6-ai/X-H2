# Опыт 18.11.2026: MS+ES при 1/1000 (только чтение резервной копии)

Настройка владельца: затвор MS+ES, выдержка 1/1000, режим M, серия CH, IMAGE DISP CONTINUOUS; камера перезапущена, затем подключена в режиме USB RAW CONV./BACKUP RESTORE. В камеру ничего не записывалось: только GetObjectInfo(0) + GetObject(0). Копия: `01_MSES_1000_CH_CONT/backup.bin` (SHA-256 e096cbfc…).

| Поле | Значение |
|---|---|
| меню `UI_SETP_SHUTTER_TYPE` (копия 0x63A) | 2 = MS+ES |
| **фактический `DOTLCD_SHUTTERTYPE_OUTPUT` (0x1A8)** | **0 = MS** |
| индекс выдержки `SHUTTER_SPEED_M` (0x5B2) | 58 (= 1/1000; 56 = 1/640, 57 = 1/800) |
| фактическая выдержка (0x18C) | 100000 = 1/1000 × 100 |
| серия (0x4F8 / 0x68C) | 1 / 21 = CH |
| IMAGE DISP `REC_VIEW` (0x29B) | 2 = CONTINUOUS |

**Флаг LCD-защиты** (код 5.30 в Unicorn, `0x30308A0`, `флаг_MSES.py`): на этих данных — **0**; если подставить фактический затвор ES — **1**.

## Выводы

1. **При MS+ES камера выбирает затвор по выдержке (Д):** 1/1000 → механический (MS), 1/16000 → электронный (ES, снимок 02B от 17.11). Нормализатор `0x14F5104` (2 → 1 без учёта выдержки) — это одна ветка обработчика события `0x2DB2248`, а не правило выбора фактического затвора.
2. **LCD-защита опирается на фактический затвор (Д):** при MS+ES, CH, CONTINUOUS и 1/1000 условие не срабатывает, потому что фактически работает механический затвор; при ES та же выдержка флаг включила бы. Это сходится с описанием Fujifilm (дефект — при электронном затворе).
3. Порог перехода MS → ES для MS+ES лежит между 1/1000 и 1/16000 (по описанию камеры — около 1/8000); точное значение — следующим опытом (MS+ES при 1/8000 и 1/10000).

## Продолжение: MS+ES при 1/8000 и роль верхнего дисплея (Д)

| Копия | Как выключали | меню / фактический затвор | выдержка (индекс / факт) | флаг LCD (VM) |
|---|---|---|---|---|
| `02_MSES_8000_CH_CONT` | без перезапуска после смены выдержки | 2 / 0 | 67 / **1/1000 — устаревшее** | — |
| `03_MSES_8000_после_перезапуска` | выключение не с экрана съёмки | 2 / **2** | 67 / 1/8000 | — |
| `04_MSES_8000_выкл_с_экрана_съёмки` | выключение с экрана съёмки | 2 / **0 (MS)** | 67 / 1/8000 | **0** (при ES было бы 1) |

1. **MS+ES при 1/8000 работает механическим затвором (Д);** электронный включается только короче 1/8000 (1/16000 → ES, снимок 02B от 17.11). Порог переключения MS+ES — сразу за 1/8000 (предел механического затвора X-H2). Поэтому при MS+ES условие LCD-защиты возможно только на выдержках короче 1/8000, а при выбранном ES — начиная с 1/640.
2. **Поля `DOTLCD_*` — состояние верхнего дисплея, сохраняемое при выключении (Д).** Копия 03 (выключение не с экрана съёмки) отличается от 04 в 15 байтах: `DOTLCD_RECOORMODE` 33 вместо 36, `DOTLCD_CONTMODE` 0 вместо 1, `DOTLCD_CONTINUOUS` 0 вместо 21 (CH), `DOTLCD_UNKNOWNSTATUS_OUTPUT` 255 вместо 40, `DOTLCD_EXPOSUREMETER_OUTPUT` 15 вместо 14, `DOTLCD_SHUTTERSPEED` 0 вместо 69, затвор 2 (значок выбора) вместо 0 (фактический). Состояние «33 / 0 / 255» — дисплей вне экрана съёмки.
3. **Методика (поправка):** «фактические» поля резервной копии достоверны, только если камеру выключили с экрана съёмки после установки настроек. Синхронизатор `0x2BD5114` переносит в них живое состояние съёмочной структуры (`+0x19AC/+0x1994`), а LCD-оценщик в прошивке читает живое состояние, а не копию.

## MS+ES при 1/10000 — порог закрыт (Д)

`05_MSES_10000` (выключение с экрана съёмки; SHA-256 3581beb6…): меню 2 (MS+ES), **фактический 1 (ES)**, индекс выдержки 68, фактическая выдержка 1000000 = 1/10000, CH, CONTINUOUS; **флаг LCD (VM) = 1** — предсказание сбылось.

**Итог по MS+ES:** механический затвор до 1/8000 включительно (индекс 67), электронный — с 1/10000 (индекс 68). Флаг LCD-защиты при MS+ES, CH и CONTINUOUS включается с 1/10000; при выбранном ES — с 1/640 (17.11).
