# План камерных проявок для проверки взаимосвязей

## Цель и уже имеющиеся контрольные файлы

Проявки `0300`, `0301`, `0303–0305`, `0307–0310` уже существуют и сопоставлены по записанным настройкам и SHA-256. **Делать их заново не нужно.** Для пяти сочетаний ниже достаточно одной совместной проявки на каждую пару, плюс повтор исходной базы. Такое сокращение опирается на имеющиеся однофакторные варианты; одна повторная база не доказывает повторяемость каждой установки или сохранения в каждой сцене.

Все фото группы A необходимо получить именно из `DSCF0296.RAF`. По метаданным его рецепт: Classic Negative, Цвет +1, света +1,5, тени +0,5, Color Chrome Effect Strong, FX Blue Strong, WB 5750 K, Clarity +3, резкость −1, HIGH ISO NR −4. Сырой WB FineTune `20, −100` — не экранные значения, не вводите их вручную. JPEG `0300` имеет FINE, O 3:2 (7728×5152), sRGB.

## Общий порядок для каждого выхода группы A

1. В просмотре откройте **исходный `DSCF0296.RAF`**, не JPEG и не другой RAF.
2. Выберите **RAW CONVERSION → REFLECT SHOOTING COND.** / «отразить условия съёмки».
3. Для всех вариантов одинаково задайте **JPEG, FINE, размер O 3:2**. Проверьте имитацию Classic Negative, Color +1, Color Chrome Strong, FX Blue Strong, WB 5750 K; остальные настройки восстановленного рецепта оставьте как есть, включая сдвиг WB, DR, зерно, LMO, цветовое пространство.
4. Измените **ровно пункты, указанные в строке** таблицы ниже. Для тона проконтролируйте, что обе отдельные величины света/тени после ввода соответствуют строке. Для WB убедитесь, что камера не сбросила сдвиг WB.
5. Нажмите Q для предварительного просмотра и MENU/OK для сохранения. Запишите получившееся имя файла рядом с меткой A0…A5. Вернитесь к `DSCF0296.RAF` и перед следующей строкой **снова** выполните REFLECT SHOOTING COND. Не переносите изменения из предыдущей строки.

| Метка | Что изменить относительно восстановленного исходного рецепта | Какой вопрос |
|---|---|---|
| **A0** | Ничего не менять; исходные света +1,5, тени +0,5, Цвет +1, Chrome Strong, FX Blue Strong, WB 5750 K, Clarity +3, резкость −1, NR −4 | Повтор `0300`: оценка повторяемости базы |
| **A1** | **Света 0 и тени 0** одновременно | Совместное действие светов и теней |
| **A2** | **Цвет 0 и Color Chrome Effect Off** одновременно; FX Blue остаётся Strong | Color × Color Chrome |
| **A3** | **WB 5000 K и Color Chrome Effect Off** одновременно; Color +1 и FX Blue Strong оставить; WB shift не менять | WB × Color Chrome |
| **A4** | **Clarity 0 и Sharpness 0** одновременно | Clarity × резкость |
| **A5** | **Sharpness 0 и HIGH ISO NR 0** одновременно | Резкость × шумоподавление |

Для A3 внимательно проверьте сдвиг WB: если камера изменила его автоматически и восстановить прежний нельзя, запишите это и не считайте вариант чистым экспериментом. Если камера делает какой-то пункт недоступным или автоматически изменяет другой, не подбирайте замену наугад: отметьте метку и фактическое состояние.

## Группа B: FX Blue и его сочетание с Color Chrome

В 0296 практически нет насыщенного синего. В 518 доступных RAF просмотрены только уменьшенные встроенные JPEG-превью: у **`DSCF9835.RAF`** есть значительные области, попавшие в выбранные синий и тёплый диапазоны Lab; это удобный кандидат, а не предсказание действия FX Blue. Подбор воспроизводится [скриптом](найти_синий_RAW.py), результаты — [здесь](подбор_RAW.json). Если этот исходный RAF ещё доступен для просмотра и RAW-конверсии **на карте камеры**, используйте его. Наличие файла на компьютере само по себе не гарантирует, что камера распознает его после переноса на карту.

Если `DSCF9835.RAF` в камере недоступен, возьмите другой RAW X-H2 с отчётливыми синими участками; по возможности также включите красный или зелёный объект и нейтральную серую/белую область без пересвета. Можно снять один новый неподвижный сюжет в RAW. Не используйте в качестве исходника JPEG из Lightroom. Дальнейшие пять JPEG создаются **все из одного и того же выбранного RAW**. Запишите имя исходного RAF.

Перед каждой проявкой B1–B5 заново откройте этот RAF, выберите REFLECT SHOOTING COND., одинаковые JPEG/FINE/O 3:2. Оставьте остальные настройки **одинаковыми**, включая имитацию плёнки, Color, света, тени, WB и его сдвиг. Не обязательно приводить их к рецепту 0296: важно сохранять одинаковый набор для всех пяти JPEG и записать его. Затем выставьте именно оба пункта строки:

| Метка | Color Chrome Effect | Color Chrome FX Blue | Назначение |
|---|---|---|---|
| **B1** | Strong | Strong | Базовая проявка |
| **B2** | Strong | Off | Действие FX Blue при Chrome Strong |
| **B3** | Off | Strong | Действие Color Chrome при FX Blue Strong |
| **B4** | Off | Off | Совместное выключение |
| **B5** | Strong | Strong | Повтор B1 — контроль повторяемости |

Сразу фиксируйте реальные имена B1–B5. B1 и B5 — намеренный повтор одной и той же настройки, а не два разных уровня эффекта. Если какой-то пункт недоступен, зафиксируйте это; руководство FUJIFILM оговаривает зависимость доступности параметров RAW-конверсии от условий съёмки.

## Как передать данные

Скопируйте созданные JPEG без обработки и без переименования, а также выбранный синий RAF, в отдельную директорию; желательно группы A и B разместить в разных подпапках. Сообщите путь и таблицу соответствия меток реальным именам JPEG и имени синего RAF. Исходный `DSCF0296.RAF` и старые `0300–0310` уже есть в проекте, повторно копировать их не нужно. Фото не стирать и не форматировать карту ради эксперимента. Компьютер к камере подключать не обязательно — файлы можно перенести удобным способом.

## Как будут сравниваться сочетания

Для параметров A и B сравним JPEG совместного изменения с базовым и двумя уже имеющимися одиночными изменениями: остаток `f(A+B) − f(A) − f(B) + f(база)` в выбранной метрике. Это описывает неаддитивность **готовых JPEG в выбранном пространстве и данной сцене**, но не доказывает прямую внутреннюю связь блоков: вклад могут давать нелинейность преобразования, маски, сжатие и повторяемость. Для группы B такая же 2×2 схема проверяет Chrome × FX Blue на сцене с синим.

[Машинная проверка существующих контролей](план.json); запуск: `python -X utf8 Анализ_прошивки/Взаимосвязь_продолжение/План_проявок/проверить_базу.py`. Проверяются выбранные теги и SHA-256 исходных JPEG, не все скрытые условия.

Последовательность входа в конверсию, Q для предварительного просмотра, MENU/OK для сохранения и перечень доступных параметров сверены с [руководством FUJIFILM X-H2: RAW CONVERSION](https://fujifilm-dsc.com/en-int/manual/x-h2/playback/menu_playback/index.html#raw_conversion).
