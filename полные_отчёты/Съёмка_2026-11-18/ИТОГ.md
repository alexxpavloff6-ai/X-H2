# Итог: настройки съёмки X-H2 5.30 через общие функции записи и чтения (18.11.2026)

Координатор — Claude Opus 5.5; исполнители Codex gpt-6-luna (xhigh): S1 затвор/серия/экспозиция, S2 фокус. Камера не использовалась; проверка — по 17 резервным копиям серии 17.11 (одна настройка на снимок). Координатор выборочно перечитал байты выдержки, затвора, серии и IMAGE DISP — совпали.

## Главное

1. **Настройки съёмки идут через те же общие функции, что и рецепт (Д):** запись `0x2C88E98` (таблица `0x33A77E8`), чтение `0x2C93FD4` (таблица `0x33A929C`).
2. **У настроек съёмки два слоя: выбор в меню и фактическое состояние (Д).** Меню: тип затвора `UI_SETP_SHUTTER_TYPE` 0x827 (копия `0x63A`: 0 MS, 1 ES, 2 MS+ES, 3 EF), выдержка M `UI_SETP_SHUTTER_SPEED_M` 0x8A0 (копия `0x5B2`, индекс по 1/3 ступени: 38 = 1/25, 52 = 1/250, 55 = 1/500, 56 = 1/640, 67 = 1/8000, 70 = 1/16000), серия `UI_SETP_CONTINUOUS` 0x858 (`0x4F8`). Фактическое: затвор `UI_SETP_DOTLCD_SHUTTERTYPE_OUTPUT` 0xAB8 (`0x1A8`; при MS+ES и 1/16000 = ES), выдержка 0xAAB (`0x18C`, знаменатель × 100), режим серии `DOTLCD_CONTINUOUS` 0xACE/0xACF (`0x68C/0x68D`: S 0, CH 21, CL 23); IMAGE DISP — `UI_SETP_REC_VIEW` 0xB (`0x29B`: 2 CONTINUOUS, 3 OFF).
3. **Условие LCD-флага читает фактический слой (Д/К):** таблица `0x3456B20` даёт условие только для фактического ES и выдержки 1/640 и короче (в шкале банка — индекс ≥ 56), вместе с CH и CONTINUOUS. Совпадает с четырьмя факторами, найденными на камере 17.11.
4. **Записи затвора и серии не ограничиваются одним байтом (Д по коду, К по смыслу):** ветка затвора `0x2C9154C` после записи вызывает `0x12ECE24`; ветка серии `0x2C8F508` — `0x13273D0`, `0x1321B28`, `0x1321D00`; ветки скорости серии `0x2C8FCB8` проверяют режим съёмки и меняют режимное поле 0x874.
5. **Фокус (S2):** `500A` → `UI_SETP_FOCUS_MODE` 0x8C0 (1 MF, 0x8001 AF-S, 0x8002 AF-C); `501C`/`D02A`/`D02B`/`D02D` — четыре USB-копии одной `UI_SETP_FOCUS` 0x6FB (точка/зона/широкая); распознавание объектов `D1BD` → `DETECT_SUBJECT_QMENU` 0x622 → `DETECT_SUBJECT` 0x620 и при большинстве значений выключает распознавание лиц 0x618 (зависимость в коде сеттера); AF-C Set `D232` → `AFC_SET_CALL` 0x70D, параметры наборов — шесть семейств `TARGET_CHASE/SPEED/PRIORITY`; PRE-AF `D34B` → 0x1E2; `D304` → `FUNC_PERFORMANCE` 0x5BE, ветка раскладывает USB-вариант на группу 0x5BA–0x5BD.
6. **Открыто:** окончательный писатель фактического затвора и фактической выдержки (найден только синхронизатор выходных полей — сходится с тем, что они обновляются при перезапуске питания); соответствие координат зоны AF внутренним полям; потребители настроек AF за пределами общего геттера (список кандидатов — в `S2_фокус/результат.json`).

## Что это даёт для доработок

- Порог LCD-защиты задан в индексах выдержки банка (≥ 56 = 1/640): если когда-нибудь менять условие, править нужно таблицу `0x3456B20`, а не меню.
- Любая логика «если выбран X, то фактически Y» живёт в фактическом слое; менять поведение камеры надо там, а меню — только представление выбора.
- Зависимость «распознавание объектов выключает лица» реализована прямо в ветке сеттера — образец того, как прошивка связывает настройки.
