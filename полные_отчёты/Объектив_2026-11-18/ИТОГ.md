# Итог: поток lenscom и параметры ручного фокуса — 5.30 против 5.33 (18.11.2026, шестой круг)

Координатор — Claude Opus 5.5; исполнители Codex gpt-6-luna (xhigh): L1 сравнение lenscom, L2 свойства объектива. Камера не использовалась.

## Главное

1. **Поток lenscom в 5.33 не изменился (Д, L1).** Регистратор, обработчик, классификатор, переключатель и все 112 кодировщиков совпали по нормализованным инструкциям; адреса сдвинуты на −0x8FD8 (обработчик `0x13EB4DC` → `0x13E2504`, таблица `0x1912414` → `0x1910654`, 108 из 108 переходов совпали). Новых кодов и веток нет; сравнений с `0x411` внутри lenscom нет.
2. **Исправление XF30mm Macro сделано только на стороне операций ручного фокуса (Д).** Сравнений `0x411` в блоке 1 стало 17 вместо 15: два новых — в конструкторах запросов, они передают признак «объектив = 0x411» диспетчеру MF (`0x2CEB0E4` / в 5.33 — аналог). В блоке 0 ещё четыре сравнения `0x411` (таблица/маршрут ID `0x114BD94`, сборка ID из двух байтов `0x15145F4`; рядом `0x410/0x412/0x413`) — одинаковы в обеих версиях.
3. **«Свойства объектива» `0x1DB2…0x1DC2` — ячейки общего байтового массива параметров (Д, L2).** Доступ — `0x149AE2C` (u8 `0x149B0CC`, u16 `0x149B18C`, младший байт первым) по указателю `0x20C1458` в рабочей памяти; пары «шаг u8 + значение u16» по классам операций: `0x1DB2/0x1DB8`, `0x1DB3/0x1DBA` (старая MF-ветка), `0x1DB4/0x1DBC`, `0x1DB5/0x1DBE`, `0x1DB6/0x1DC0`, `0x1DB7/0x1DC2`. Писателя в коде нет, указатель статически не устанавливается (координатор проверил записи по `0x20C1458` во всех блоках) — массив заполняется во время работы; lenscom в него не пишет. Источник (заводские параметры из флеша или данные объектива) — Г.
4. **Что исправила Fujifilm (Д по коду):** в 5.30 основная MF-ветка брала шаг и значение из массива параметров (`0x1DB3`/`0x1DBA`); в 5.33 эти ячейки больше не читаются — для объектива `0x411` подставлены константы шаг `0x8C`, значение `0xE4`, для остальных — шаг `0x80`, значение 0. Остальные пары параметров используются как прежде. Изменение касается операций MF `0x1E/0x20`, не алгоритма автофокуса.

## Что это даёт для доработок

- Образец того, как производитель правит поведение под конкретный объектив: не меняя обмена с объективом (lenscom), а добавляя проверку lens ID в конструкторе запроса и подменяя параметры в диспетчере операций. Такая правка — несколько инструкций в двух местах.
- Параметры ручного фокуса по классам операций (шаг/значение) задаются массивом `0x20C1458`; изменить чувствительность MF для класса операций можно было бы через эти значения — но их источник нужно сначала установить (опыт на камере).
