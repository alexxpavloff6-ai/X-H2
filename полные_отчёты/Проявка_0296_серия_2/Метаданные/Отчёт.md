# Метаданные новой серии проявок DSCF0296

## Вывод и ограничения

Владелец сообщил, что восемь JPEG получены в камере из одного DSCF0296.RAF и в каждом изменён один параметр относительно DSCF0300.JPG. Записанные целевые теги согласуются с этим сообщением и указанным порядком; **это не доказывает происхождение пикселей, неизменность скрытых настроек или причинность различий изображения**. При изменении температуры WB изменились также записанные WBRed и WBBlue; при изменении резкости — отдельный стандартный EXIF Sharpness. Это дополнительные фототеги, совместимые с зависимыми изменениями, а не доказательство независимого изменения оператором. Повторной независимой проявки с теми же настройками нет, поэтому небольшие различия изображений нельзя надёжно отделить от повторяемости и кодирования.

Исходная съёмка и создание JPEG отмечены одинаковыми доступными временными тегами; дата изменения новых JPEG идёт в заявленном порядке. Камерные часы и EXIF могут быть скопированы или неверны. Доступные идентифицирующие признаки камеры и объектива и счётчик изображения во всех файлах совпадают с 0300; значения не публикуются. Их совпадение не доказывает общность исходных пикселей. GPS, серийные номера и снимки не экспортируются.

## Сопоставление с DSCF0300

Столбец чисел — значения ExifTool `-n`; в скобках — отображаемое значение. Это ValueConv без PrintConv, не обязательно исходные байты или линейная шкала. Каждая строка сравнивается с одним и тем же 0300, не с предыдущим JPEG.

| JPEG | Целевой тег относительно 0300 | Дополнительные отличающиеся фототеги | Длина миниатюры, байт |
|---|---|---|---:|
| 0303 | HighlightTone −24 (+1,5) → 0 (0) | нет обнаруженных | 8818 |
| 0304 | ShadowTone −8 (+0,5) → 0 (0) | нет обнаруженных | 8828 |
| 0305 | ColorChromeEffect 64 (Strong) → 0 (Off) | нет обнаруженных | 8944 |
| 0306 | ColorChromeFXBlue 64 (Strong) → 0 (Off) | нет обнаруженных | 8837 |
| 0307 | ColorTemperature 5750 → 5000 K | WBRed 638 → 581; WBBlue 428 → 475 | 8991 |
| 0308 | Clarity 3000 (+3) → 0 (0) | нет обнаруженных | 8935 |
| 0309 | FujiFilm Sharpness 130 (−1) → 3 (0) | ExifIFD Sharpness 1 → 0 | 8840 |
| 0310 | NoiseReduction 736 (−4) → 0 (0) | нет обнаруженных | 8821 |

Для 0300 длина миниатюры 8847 байт. Во всех восьми также различаются ModifyDate и производный SubSecModifyDate. Записанные ModifyDate по порядку: 0300 — 2026-11-08 08:08:51; 0303–0310 — 2026-11-09 05:47:46, 05:48:17, 05:48:35, 05:48:53, 05:49:28, 05:49:54, 05:50:12, 05:50:45. Других отличий сохранённых распознанных неприватных тегов между каждым новым JPEG и 0300 не найдено. Полные разности, включая наличие полей, — в JSON.

Во всех JPEG и RAF `WhiteBalanceFineTune` равен `20 -100` (ExifTool: Red +20, Blue −100), WBGreen равен 302. Это подтверждает сохранение записанного сдвига при 0307, но не доказывает одинаковость всех скрытых параметров или полученного цвета. Все JPEG помечены Fuji `ImageGeneration=1` / Re-developed from RAW, RAF — `0` / Original Image. Все JPEG отмечены Classic Negative и цветом +1. Интерпретации соответствуют ExifTool 13.61; отображаемая камерная строка не является независимой проверкой исполняемой прошивки.

Неизвестные доступные теги извлечены с `-u -U` и сравнены также отдельно по наличию и равенству: между новыми JPEG и 0300 различий нет, в том числе для числовых неизвестных. Поскольку значение неизвестного тега может оказаться идентификатором, его значение намеренно не публикуется — только наличие и равенство. Одинаковые неизвестные поля не доказывают одинаковость неизвестных или незаписанных настроек; содержимое неизвестных массивов RAFData в сопоставление не включено.

## JPEG и RAF

Все девять отдельных JPEG: 7728×5152, Fuji Quality FINE, CompressedBitsPerPixel 4,8, 8 бит на компоненту, три компоненты, baseline DCT/Huffman, YCbCr 4:2:2. У всех одинаков SHA-256 полезной нагрузки единственного DQT-сегмента до первого SOS: `d2b12256fe299ccf46695d579a4f74c6c41705746432cd54a390688b9a62404a`. Это сравнение таблиц квантования, а не доказательство одинакового качества, пикселей или остальных этапов кодирования. Файловый размер варьируется и сам по себе качество не измеряет.

ExifTool не выявил ICC-тегов; парсер заголовков до первого SOS не обнаружил APP2 `ICC_PROFILE`. EXIF ColorSpace отмечен sRGB. Это не измерение соответствия цвета sRGB и не полноценная проверка всей поточной структуры после первого SOS. Полный список обнаруженных до первого SOS маркеров и длин приведён для каждого JPEG в JSON; содержимое изображения не сохраняется.

Сравнение RAF с JPEG неоднородно: ExifTool видит встроенный предпросмотр 4416×2944, Fuji Quality NORMAL и CompressedBitsPerPixel 3,2; эти поля не описывают качество массива RAW. В RAF доступны дополнительные RAW-поля, в том числе полный размер 7872×5196, crop 7728×5152, 14 бит и RAFCompression 0. Наряду с ImageGeneration и Quality отличаются, например, координаты FocusPixel в системе размеров предпросмотра, разрешения, наличие RAW-специфичных полей и временные/служебные поля. Полный список обнаруженных неприватных различий и раздельное наличие неизвестных полей — в JSON; отсутствие поля в одном формате не является изменённой настройкой.

## Метод и целостность

Исходники считаны локально только на чтение; до и после анализа все десять SHA-256 совпали. Оба хэша и размер каждого файла записаны в [метаданные.json](метаданные.json). Это не доказывает неизменность до первого и после последнего чтения. ExifTool получает байты через stdin; сценарий не изменяет исходники и прерывает запись JSON при изменении хэша. Использованы локальные Python и ExifTool 13.61, опции `-j -G1:4 -a -u -U -charset UTF8`, отдельно с `-n` и без него. Имена `Copy1` в JSON различают одноимённые теги в группах ExifTool. Сравниваются доступные теги, а не все потенциальные нерасшифрованные байты MakerNote; неизвестные массивы RAFData исключены.

Запуск из любого каталога:

```text
python Анализ_прошивки/Проявка_0296_серия_2/Метаданные/исследовать.py --exiftool ПУТЬ_К_EXIFTOOL --perl ПУТЬ_К_PERL
```

`--perl` нужен для Perl-версии ExifTool. Сценарий перезаписывает только собственный JSON; другая версия ExifTool может по-другому интерпретировать или извлекать теги. Описание полей: https://exiftool.org/TagNames/FujiFilm.html
