# Итог: карта свойств рецепта X-H2 5.30 «USB → внутренняя настройка → код → байты банка» (18.11.2026)

Координатор — Claude Opus 5.5; исполнители Codex gpt-6-luna (xhigh): R1 снимок/плёнка/DR, R2 WB/тона/цвет/эффекты, R3 общий слой USB. Камера не использовалась (опыт с зерном и D1A5 — в `Зерно_2026-11-18`). Координатор выборочно сверил байты банка (цвет, Kelvin, NR, WB, DR, качество, плёнка, приоритет DR) с резервной копией — совпали.

## Главное

1. **Все свойства рецепта слота проходят через два общих распределителя прошивки (Д по коду).** Запись: `0x2C88E98(id, value)` — таблица переходов `0x33A77E8`, индекс `id − 0xB`. Чтение: `0x2C93FD4(id)` — таблица `0x33A929C`, индекс `id − 0xF`. У каждой внутренней настройки своя ветка; значения переводятся через `0x1135930` / `0x12E67AC` и таблицы `0x1BD5AB8 + 8·id`; в банк пишет `0x11335C4(id, value, 0)` (оболочка над `0x12AA680`).
2. **По байтам банка предсказаны ответы камеры по USB для всех семи слотов** — R2: 15 свойств, 105 из 105; R1: D18E–D194 согласуются со всеми наблюдениями. Внутренние байты почти никогда не равны USB-значениям — это таблицы и смещения (сводка ниже).
3. **Сдвиги WB хранятся по режимам баланса белого (Д код + данные).** `D19A/D19B` пишут в поле того семейства WB, что выбрано в слоте (Auto, Kelvin, Daylight/Clear, Bulb, …; функции выбора `0x13340C0` / `0x1334404`); USB = 9 − байт.
4. **Температура WB пишется без проверки режима WB (Д по коду).** Ветка `0x2C8A738` не смотрит `D199`. Правило fujicli «не писать Kelvin при другом WB» — ограничение инструмента, не камеры.
5. **Объединённые настройки:** зерно (`0x108` → GRAIN + GRAIN_SIZE) и размер снимка (`D18E` → PIXEL + ASPECT, сеттер PIXEL `0x2C8E1C4` с таблицей 26 сочетаний; точная таблица слота — К).
6. **Граница статического разбора (R3):** на стороне USB найдено место, где событие `0x1F` вызывает общий сеттер с парой «внутренний id + значение» из контекста `0x26a70a8 + 0x108f0/0x108f4` (`0x2BDFBCC`). Сами эти поля не пишутся отдельными инструкциями ни от какой базы (координатор проверил все записи по смещениям 0x8f0/0x8f4 в блоках 0–2) — их заполняет копирование сообщения очереди. Поэтому перевод «PTP-код свойства + USB-значение → id + значение», отказ 0x201C и сборка 6/7 статически не находятся; нужна эмуляция задачи USB целиком или трассировка на камере.
7. **Открыто:** где хранится имя слота (`D18D`, `CUSTOM_SAVE_NAME` — поля в карте банка нет); точная таблица `D18E`; соответствие WB «как снято» (USB 0x0000) — в слотах не встречается; NR проверено только на одном значении (−4 во всех слотах).

## Сводка кодировок «байт банка → USB» (слот)

| USB | Внутренняя настройка | Байт банка → USB |
|---|---|---|
| D18F качество | QUALITY 0x670 | 4/0/1/2/3 → RAW/Fine/Normal/Fine+RAW/Normal+RAW (1/2/3/4/5) |
| D190 DR | DRANGE 0x6A6 | 0/1/2/3/4 → Auto(0xFFFF)/100/200/400/800 |
| D191 приоритет DR | WIDEDRANGE 0x6B0 | 4/3/2/1/0 → Off/Weak/Strong/Plus/Auto (0/1/2/3/0x8000) |
| D192 плёнка | FILM_SIM 0x68E | таблица `0x1758BD0`; например Classic Chrome 15 → 11, Classic Neg 16 → 17, Velvia 4 → 2 |
| D193 / D194 ч/б тонировка | BLACK_TONE 0x6A2 / _RG 0x6A4 | 18 → 0, шаг 1 байт = 10 USB (обратный порядок) |
| D195 зерно | GRAIN 0x106 + SIZE 0x107 (через 0x108) | Off → 6 + SIZE, иначе 3 + 2·SIZE − GRAIN |
| D196 / D197 / D198 | SHADOWING 0x109 / BLUE_EFFECT 0x10A / SMOOTH_SKIN 0x10B | 0/1/2 → Off/Weak/Strong (1/2/3) |
| D199 WB | WB 0x5F5 | индекс → код USB по таблице (0 Auto, 3 Daylight, 8 Incandescent, 10 Kelvin) |
| D19A / D19B сдвиги | WB_TUNING_R/B 0x6BF/0x6DD → поле семейства WB | USB = 9 − байт |
| D19C Kelvin | WB_KELVIN 0x5F7 | u16 = Кельвины |
| D19D / D19E тона | HIGHLIGHT 0x6B9 / SHADOW 0x6BB | USB = (байт − 4) × 5 |
| D19F цвет / D1A0 резкость | STILLCOLOR 0x6B3 / SHARPNESS 0x6B5 | переставленные таблицы, ×10 |
| D1A1 NR | NR 0x603 | таблица `0x1766F70`: 0…8 → 8000,7000,4000,3000,2000,1000,0000,6000,5000 |
| D1A2 Clarity | CLARITY 0x605 | USB = (байт − 6) × 10 |
| D1A3 LMO / D1A4 цветовое пространство | LEQ 0x615 / COLOR_SPACE 0x104 | 0/1 → 1/2 |

## Что это даёт для доработок

- Любая настройка рецепта меняется в одном месте: ветка сеттера `0x2C88E98` и таблица перевода `0x1BD5AB8 + 8·id`. Добавить значение (например, новую ступень) — значит поправить таблицу и диапазон в ветке; USB-слой и меню берут перевод оттуда же.
- Банк настроек хранит внутренние индексы, а не «человеческие» значения; инструмент, который правит резервную копию напрямую, должен использовать эти таблицы (сводка выше), иначе получит другие настройки.
- Для изменения поведения USB (например, разрешить запись 6/7 зерна) статического разбора мало: нужен разбор очереди сообщений USB-задачи.
