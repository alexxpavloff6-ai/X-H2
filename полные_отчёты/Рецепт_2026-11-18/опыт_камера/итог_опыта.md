## Выводы

1. **Шумоподавление и Clarity — модель R2 подтверждена записью (Д).** NR: таблица `0x1766F70` (USB 0x2000 → индекс 4); Clarity: байт = USB/10 + 6.
2. **Правило «размер не для RAW» проверяет сама камера (Д).** Запись `D18E` в слот с качеством RAW отвергается с 0x201C даже для текущего значения; в слоте FINE+RAW та же запись принимается. Это первое найденное правило совместимости, которое камера применяет при записи по USB (правило fujicli совпадает).
3. **Размер слота кодируется той же таблицей, что и текущий размер (Д):** 0x12 → PIXEL 1 (M), ASPECT 0 (4:3); 7 → PIXEL 0 (L), ASPECT 1 (3:2).
4. **WB «как снято» (0x0000) в слоте недопустим (Д):** это значение бывает только у профиля проявки D185.
5. **Имя слота хранится однобайтной строкой с нулём в конце** по смещению копии `0xF9BD` для C1 (+0x400 на слот), вне полей нашей карты банка (Д). USB отдаёт её в UTF-16.
6. **Контрольный байт `0xE4` — сумма байтов (Д):** изменения ровно на сумму изменённых байтов (+4, +4, 0, имя −0x1B).
