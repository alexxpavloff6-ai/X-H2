# C3. История fujicli: что узнали о камерах и куда движется проект

Срез на 18.11.2026. Локальный клон <корень проекта>\Внешние_репозитории\fujicli, ревизия 27d3a6b, 112 коммитов; первый датирован 12.10.2025, последний — 17.11.2026. Проект — Rust/CLI с лицензией AGPL-3.0-or-later. README подчёркивает: широко испытана только X-T5; совместимость остальных моделей не гарантируется.

## Выводы для владельца

1. fujicli — ценный каталог знаний о внешнем интерфейсе камеры: USB/PTP, коды свойств, кодировки значений, диапазоны, зависимости и различия между моделями. Это не карта прошивки и не описание внутреннего пути обработки кадра.
2. Проект прошёл путь от PTP-команд и рецептов к резервным копиям и камерной проявке RAW, а затем к FML — декларативному языку камер, который описывает свойства и правила и порождает программный код.
3. X-H2 и X-H2S распознаются как модели с X-Processor 5, но для них сейчас заявлено только чтение сведений об устройстве. Резервная копия, рецепты и проявка для X-H2 не включены.
4. Одинаковый X-Processor 5 сам по себе не означает одинаковую поддержку: у X-T5 есть backup, 7 слотов и проявка; у X-S20 — backup, 4 слота, без проявки; X-H2 остаётся только в списке распознаваемых моделей.
5. Исправления показывают реальные тонкости: Grain Effect Off бывает кодами 0x01/0x06/0x07; RAW не имеет размера JPEG; RAW+JPEG при проявке сводится к соответствующему JPEG-качеству; WB-сдвиги сохраняются с «Как снято»; Auto в динамическом диапазоне означает сохранить исходное состояние.
6. Правила FML годятся как стартовая схема свойств и связей, но значения X-T5 нельзя без проверки переносить на X-H2.
7. Наш анализ X-H2 дополняет fujicli глубже: мы разобрали backup на внутренний банк и преобразования, а также проследили отдельную запись 0x4C и флаг. fujicli описывает backup как непрозрачный объект, который копируется без разбора.
8. GitHub-зеркало содержит шесть issues/PR на дату проверки. Оно не пустое, но README и CONTRIBUTING говорят, что основной хостинг — Gitea, где изменения появляются первыми.

### Как устроена модель FML

FML связывает название настройки, тип, варианты или диапазон/шаг, код PTP, таблицу кодирования, модель камеры, аппаратный признак и правила зависимости. Например, температура WB указана 2500–10000 K с шагом 10; WB shift — −9…+9; значение «температура» применимо только при соответствующем WB-режиме. Правила также описывают условно отсутствующие поля и преобразования профиля. Документация сообщает, что поля читаются в порядке зависимостей и неприменимые параметры оставляются пустыми.

Это хороший образец таблицы внешних свойств для X-H2: хранить код, значение, диапазон, условие, модель/версию и отдельное подтверждение. Сама схема, однако, не доказывает внутреннюю реализацию прошивки.

## 4. Куда движется проект и что ещё не поддерживает

11–17 ноября автор в основном улучшал Windows-подключение, выбор нужной камеры, получение профиля проявки и сохранение условий исходного кадра. Код переносит шаблоны по свойствам сенсора/процессора, но включение функций остаётся модельным. Исправления последнего дня сосредоточены на WB, RAW/JPEG и корректном представлении размеров.

Документация показывает:

| Модель | Процессор | Backup | Слоты | Проявка |
|---|---|---:|---:|---:|
| X-T5 | X-Processor 5 | да | 7 | да |
| X-S20 | X-Processor 5 | да | 4 | нет |
| X-H2 / X-H2S | X-Processor 5 | только распознавание, доступно device info | — | не заявлена |

README отдельно оговаривает, что широко проверена только X-T5. Поэтому совпадение процессора или сенсора — полезная гипотеза для общих шаблонов, но не основание включать запись/backup/render на X-H2.

### GitHub-зеркало и обсуждения

Проверка GitHub API на 18.11.2026 вернула шесть записей: #1–#6. В их числе исправление кодов зерна (#2), открытый PR добавления X-T30 III (#3), замечание о размерах X-T5/26 Мп (#4), извлечение профиля из MakerNotes (#5) и предложение разбирать/редактировать backup X-T30 III (#6). PR #6 закрыт без слияния с меткой wontfix; автор объяснил, что не хочет записывать обратно в backup обратнореверсированные байты, которые камера затем импортирует, из-за риска. Это существенная граница безопасной поддержки. CONTRIBUTING называет Gitea основным сервером и предупреждает, что зеркало отстаёт.

## 5. Что это даёт для будущих доработок прошивки

Использовать fujicli стоит как кандидатный справочник для внешних PTP-настроек: имена свойств, коды, варианты, диапазоны, шаги, зависимости и формат профиля. Для нашей карты добавить модель и версию прошивки, источник слоя (PTP/UI_SETP/backup/код), тип кодировки, условие применимости, состояние «прочитано/принимается/записано», проверку и степень уверенности.

Особенно полезны FML-приёмы: не терять Auto, явно отмечать неприменимые поля, не смешивать общие шаблоны и модельные ограничения, описывать корректировки профиля отдельными правилами. Переносить значения X-T5 на X-H2 можно только после подтверждения по X-H2 или прошивке именно нужной версии. История PR #6 дополнительно показывает осторожность автора к редактированию backup: использовать схему как справочник, а не как разрешение менять файл, предназначенный для восстановления.
