# Контрольные снимки X-H2: Classic Chrome, рецепт и Reala ACE

## Основной вывод

Проверена серия владельца из `Тестовые фото`: восемь RAW и шесть отдельных JPEG. Условия и метаданные позволяют сравнить два варианта **Classic Chrome «Цвет 0» и «Цвет +2»**. На этой сцене в четырёх попарных сравнениях после приблизительного совмещения кадров значение +2 устойчиво даёт большую цветность. Это **визуальная проверка результата конкретной камеры и сцены**, но не доказательство внутренней формулы прошивки или универсальной разницы для всех цветов.

Для двух кадров пользовательского рецепта есть RAF со встроенными JPEG-предпросмотрами, но отдельных файлов `DSCF0296.JPG` и `DSCF0297.JPG` не существует: **владелец уточнил, что его пресет сохраняет только RAW**. Встроенные превью можно изучить, но они не заменяют автоматически полноразмерные JPEG. Дополнительно эти два кадра сняты с другой выдержкой и другими настройками, поэтому их вид не является изолированным эффектом рецепта.

**Продолжение:** владелец позднее проявил `DSCF0296.RAF` в камере при «Цвет +1», 0 и +2; это новые файлы `DSCF0300–0302.JPG`, а не найденные оригинальные JPEG съёмки. [Сравнение трёх проявок одного RAW](../Проявка_0296/Сравнение_проявок_XH2.md).

## 1. Состав серии

Сопоставление основано на порядке, сообщённом владельцем, и поддержано возрастающим временем съёмки, имитацией и настройкой насыщенности в Fuji MakerNote. Время — значение часов камеры.

| Файл | Серия | Базовая имитация по тегу | Цвет по тегу | Выдержка | Отдельный JPEG |
|---|---|---|---:|---:|---|
| `DSCF0292.RAF` | Classic Chrome 0 | Classic Chrome | 0 | 1/30 с | есть |
| `DSCF0293.RAF` | Classic Chrome +2 | Classic Chrome | +2 | 1/30 с | есть |
| `DSCF0294.RAF` | Classic Chrome +2 | Classic Chrome | +2 | 1/30 с | есть |
| `DSCF0295.RAF` | Classic Chrome 0 | Classic Chrome | 0 | 1/30 с | есть |
| `DSCF0296.RAF` | рецепт владельца | **Classic Negative** | +1 | 1/20 с | **нет в папке** |
| `DSCF0297.RAF` | рецепт владельца | **Classic Negative** | +1 | 1/20 с | **нет в папке** |
| `DSCF0298.RAF` | Reala ACE 0 | Reala ACE | 0 | 1/30 с | есть |
| `DSCF0299.RAF` | Reala ACE 0 | Reala ACE | 0 | 1/30 с | есть |

Все имеют f/2,8, ISO 125 и объектив XF16-55mmF2.8 R LM WR. Время 0292–0299 возрастает от 06:42:24 до 06:43:42 по часам камеры; их фактическая точность отдельно не проверялась. У 0292–0293 EXIF указывает 16,0 мм, у остальных — 16,5 мм. По изображениям положение и масштаб немного менялись. Пользовательские значения определены по метаданным, не по догадкам о внешнем виде.

**Важное уточнение о рецепте:** для снятых 0296 и 0297 именно поле FilmMode содержит `0x0800`, которое [таблица ExifTool Fujifilm](https://exiftool.org/TagNames/FujiFilm.html) обозначает **Classic Negative**, а не Classic Chrome. Ранее владелец упоминал также собственный рецепт на основе Classic Chrome; по файлам нельзя определить название или номер выбранного C-слота и нельзя утверждать, какой именно слот владелец намеревался выбрать. Это не опровержение наличия другого рецепта в камере.

## 2. Какие настройки фактически записаны

В таблице — поля Fuji MakerNote встроенных предпросмотров RAF, подтверждённые ExifTool; они не обязательно представляют абсолютно все настройки рецепта или условия съёмки.

| Настройка | Classic Chrome 0/+2; Reala 0 | Рецепт 0296/0297 |
|---|---|---|
| Базовая имитация | Classic Chrome или Reala ACE | Classic Negative |
| Цвет | 0 либо +2 согласно серии | +1 |
| Баланс белого | Auto, приоритет атмосферы | Kelvin, 5750 K |
| Сдвиг WB | сырые `0, 0` | сырые `20, −100` |
| Света / тени | `0 / 0` | `+1,5 / +0,5` по интерпретации ExifTool |
| Чёткость | 0 | +3 |
| Резкость | 0 | −1 |
| Шумоподавление | 0 | −4 |
| Color Chrome Effect | Off | Strong |
| Color Chrome FX Blue | Weak | Strong |
| Зерно | Off | Off |
| Development Dynamic Range | 100 | 100 |

ExifTool отображает сохранённый сдвиг рецепта как `Red +20, Blue -100`; его документация отмечает, что для новых камер эти значения следует делить на 20. По этому правилу предполагаемые значения экрана — **R +1, B −5**, но экран камеры отдельно не наблюдался. Для автоматического WB у контрольных и Reala кадров настройки камеры и её численные внутренние WB-поля не доказывают одинаковый фактический баланс между снимками. В частности, здесь контрольный WB записан **Auto**, не фиксированные 5600 K; Color Chrome FX Blue записан **Weak**, не Off. У 0296/0297 зафиксирован электронный затвор и другой режим стабилизации, чем у остальных. Эти различия не являются критикой съёмки, но важны для интерпретации.

У всех выбранных файлов EXIF сообщает f/2,8 и ISO 125. Выдержка 1/20 вместо 1/30 с — в 1,5 раза длиннее, около **+0,585 EV** при прочих равных. Следовательно пользовательские кадры отличаются не только рецептом. В RAW индексированной выборки после вычитания чёрного среднее кадров 0296/0297 оказалось примерно в 1,57 раза выше кадров 0292/0295. Это согласуется с разницей времени, но не является точным измерением её отдельного вклада: сцена и геометрия также менялись. [Метод и ограничения RAW-измерения](RAW_сенсор/Отчёт.md).

## 3. Цвет 0 и +2 в реальных JPEG

Исследованы отдельные JPEG 0292–0295. Камера/владелец записали два кадра 0 и два +2. Изображения уменьшены до 966×644 и приблизительно совмещены аффинным преобразованием. Затем в каждой паре оставлены перекрывающиеся пиксели без крайних значений каналов и со схожей яркостью: в обоих JPEG каждый RGB-канал больше 5 и меньше 250, L* опорного кадра 15–85, разность L* не более 3. Маска покрывает 49–55% рабочего изображения для четырёх интересующих пар.

| Сравнение: первый → второй кадр | Настройка | Медиана изменения цветности C*ab |
|---|---|---:|
| 0292 → 0293 | 0 → +2 | +0,91 |
| 0292 → 0294 | 0 → +2 | +0,84 |
| 0295 → 0293 | 0 → +2 | +0,91 |
| 0295 → 0294 | 0 → +2 | +0,90 |

У повторов 0→0 и +2→+2 медианный сдвиг C*ab на соответствующих масках близок к нулю. Это поддерживает вывод, что на выбранных участках **+2 действительно связано с более насыщенным результатом**, но изменения света, автоматического WB, положения и фокусного расстояния не устранены полностью. Четыре пары используют те же четыре кадра и не являются четырьмя независимыми сценами.

C*ab — расчётная цветность в пространстве CIELAB, полученная из JPEG при предположении sRGB согласно EXIF. В JPEG нет встроенного ICC-профиля; абсолютная точность цвета не калибрована. Значения **не проценты насыщенности** и не шкала камеры. При сравнении всех некрайних пикселей без ограничения ΔL* знак результата также положительный: +0,80…+0,86. Маска и регистрация влияют на численные результаты. [Полные сравнения, изображения распределений и метод](Цвет/Отчёт.md).

## 4. Рецепт и Reala ACE

**Рецепт 0296/0297.** В RAF есть встроенные изображения 4416×2944; визуально и численно они отличаются от контрольных превью. При этом у них 1/20 с, другая базовая имитация, WB и несколько параметров тона/цвета. Поэтому отличие нельзя количественно приписать только рецепту или одному его параметру. У этих двух файлов нет отдельных JPG в папке.

Для шести кадров, где есть и отдельный JPEG, и RAF-превью, предпросмотр сравнен с отдельным JPEG *того же кадра* на уменьшенной сетке. Получена медианная ΔE76 около 0,47–0,50, что показывает близкое изображение в этих конкретных парах при данном методе. Это **не доказывает** идентичности полного конвейера, разрешения, деталей или цветового поведения у 0296/0297. Встроенные изображения рецепта годятся для предварительного анализа, но не выдаются за отсутствующие полноразмерные JPEG.

Дополнительная проверка сравнила межкадровые тенденции для всех 15 пар шести кадров: отдельно JPEG↔JPEG и превью↔превью. При одинаковом методе на маске схожей яркости знаки медианных изменений L*, C*, a* и b* совпали в 15 из 15 пар для каждого параметра; максимальная разница медианного ΔC* составила 0,028. Это поддерживает **описательное** сравнение превью этой серии, но не доказывает эквивалентность изображений при иных настройках и не устраняет различия выдержки и WB рецепта. [Метод и все ограничения](Проверка_превью/Отчёт.md).

**Reala ACE 0298/0299.** Отдельные JPEG отличаются от Classic Chrome: например, медианная цветность всего уменьшенного кадра 9,75–10,06 против 7,91–8,03 у двух Classic Chrome 0. Это не прямой процент различия цвета и не калиброванная оценка плёночной симуляции. Между двумя повторами Reala также наблюдается изменение; WB автоматический и геометрия/свет могли измениться. Поэтому нельзя приписывать всю разницу только переключению имитации. В Reala около 3,18–3,28% пикселей исходного JPEG достигают ≥254 хотя бы в одном канале, против 0,10–0,11% у JPEG Classic Chrome 0. Это индикатор края *кодового диапазона JPEG*, не доказательство клиппинга сенсора.

## 5. Различный размер RAW

RAF 0296 и 0297 занимают примерно 81 МиБ каждый, остальные — примерно 36–37 МиБ. Считанное из заголовка поле сжатия `0` у двух файлов рецепта и `2` у остальных [расшифровывается ExifTool](https://exiftool.org/TagNames/FujiFilm.html#RAFHeader) как **Uncompressed** и **Lossless** соответственно. Физические размеры массива, сообщённые LibRaw, одинаковы. Это объясняет основной масштаб разницы файлов, не доказывая различия разрешения или дефекта файлов.

## 6. Что подтверждено относительно прошивки

Ранее в виртуальной памяти на X-H2 для искусственных условий Classic Chrome были рассчитаны четыре внутренних параметра; при проверенных индексах, связанных с вариантами «Цвет 0» и «+2», получались разные значения. Текущая серия независимо показывает, что соответствующие записи настройки в доступных реальных JPEG сопровождаются изменением цвета. Результаты **согласуются на качественном уровне**, но между ними остаются незакрытые звенья: не наблюдались физические регистры, индивидуальная калибровка, обработка каждого пикселя или весь путь камеры. Нельзя выводить измеренные `+0,84…+0,91 C*ab` из четырёх чисел прошивки и нельзя считать модель полностью подтверждённой. [Прежние границы трассы](../Сквозной_цвет/Сравнение_Classic_Chrome_и_Цвет.md).

В отдельном продолжении изучены параметры самого рецепта, включая света +1,5 и тени +0,5: их представления найдены в таблицах X-H2 5.30, а совместный тональный фрагмент исполнен в VM с искусственными входами. Получен массив из 40 чисел, но его воздействие на пиксели не доказано; связь имени режима `SUPERIA` с Classic Negative также не установлена. [Проверенные коды и границы](Рецепт_прошивка/Отчёт.md).

## 7. Что можно улучшить при следующем опыте

Повторять всю серию немедленно не требуется: текущая серия уже полезна и показывает разницу 0/+2. Для более строгого опыта — фиксированный WB вместо Auto, неподвижная камера и фокусное расстояние, одинаковые выдержка/диафрагма/ISO и стабильный свет; желательно нейтральная и цветовая мишени без яркого экрана в кадре. Исходных JPEG для 0296/0297 нет, поскольку применённый пресет сохраняет только RAW; анализ этих кадров ограничен RAW и встроенными предпросмотрами.

**Альтернатива без повторной съёмки:** согласно [руководству X-H2](https://app.fujifilm-dsc.com/en-int/manual/x-h2/playback/menu_playback/#raw_conversion), камера умеет конвертировать отображаемый RAW, выбрать `REFLECT SHOOTING COND.` и сохранить новую копию. Если `DSCF0296.RAF` доступен в просмотре камеры, можно при желании создать несколько *новых* JPEG из одного RAW, оставив все настройки проявки одинаковыми, кроме изучаемой, например «Цвет 0» и «Цвет +2». Зафиксировать полные настройки каждого варианта и имена сохранённых копий; проверить, что именно тип JPEG, размер L и качество Fine выбраны и доступны. Сначала сохранить резервную копию RAF. Эти JPEG являются **новыми результатами RAW-конверсии**, не исходными JPEG при съёмке; воспроизведение первоначального пользовательского вида и доступность каждой опции требуют проверки. Если RAW только на компьютере, распознавание файла камерой после копирования обратно на карту не гарантировано.
