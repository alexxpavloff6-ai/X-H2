# Уточнение: пользовательский рецепт и Lightroom

## Источник и важные исправления

Владелец сообщил, что все JPEG в каталоге получены обработкой соответствующих RAW в Lightroom, а съёмка с Classic Chrome использовала **собственный рецепт пользователя на базе Classic Chrome**, а не обязательно стандартные параметры этой имитации. Это сведения владельца; они не отменяются строками EXIF или одинаковыми тегами. Соответствующий RAF для 10 JPEG в указанной папке отсутствует, поэтому для них локальную пару проверить нельзя.

JPEG здесь — результат цепочки `RAW → обработка в Lightroom → JPEG`. Сохранённые в JPEG EXIF/MakerNote могут содержать исходные метаданные; совпадение метаданных с RAF и строка `Digital Camera X-H2 Ver5.30` **не доказывают, что JPEG создан процессором камеры или воспроизводит её рецепт**. Запись `ImageGeneration=0` в MakerNote также не опровергает сведения владельца о Lightroom. Профиль, пресеты и отдельные регулировки Lightroom этим чтением не установлены. Пользовательский рецепт, встроенный предпросмотр RAF и проявка Lightroom — три разные сущности.

## Что такое рецепт

По [руководству Fujifilm](https://www.fujifilm-x.com/en-gb/learning-centre/make-your-own-film-simulation-recipe/) рецепт — сочетание **базовой Film Simulation и дополнительных настроек**. В зависимости от рецепта и камеры это, например, баланс белого и его сдвиг, светлые и тёмные участки, цвет, резкость, чёткость, шумоподавление, динамический диапазон, зерно, Color Chrome Effect и Color Chrome FX Blue; рецепт может включать и рекомендации по экспозиции. Fujifilm позволяет хранить пользовательские наборы настроек и выбирать их; [руководство X-H2](https://fujifilm-dsc.com/en/manual/x-h2/menu_shooting/image_quality_setting/) отдельно перечисляет соответствующие параметры.

Следовательно, `FilmMode=Classic Chrome` говорит о **базовой имитации**, а не является именем или полным составом рецепта и не подтверждает нейтральные настройки. Аналогично `REALA ACE` в метаданных означает записанную базовую имитацию; состав дополнительных параметров по одному тегу неизвестен. Нельзя определять используемый пользовательский слот C1–C7 или название рецепта только по FilmMode.

## Что действительно записано в этом наборе

Проверено 518 RAF; метаданные снимков ниже берутся из **встроенных JPEG-предпросмотров RAF**, а не из отрендеренного Lightroom JPEG. Выборка по базовой имитации:

| Базовая имитация по `FilmMode` | Число RAF | Группы значений выбранных метаданных |
|---|---:|---|
| Classic Chrome, `0x0600` | 389 | Для выбранного набора тегов все 389 одинаковы. |
| Reala ACE, `0x0B00` | 122 | Две группы: 90 и 32 файла; в выбранных тегах различается сырая пара коррекции WB. |
| Classic Negative, `0x0800` | 7 | Для выбранного набора тегов все семь одинаковы. |

Для всех 389 RAW с базой Classic Chrome проверены следующие значения из встроенных MakerNote:

| Поле | Сырое значение | Как его можно читать |
|---|---:|---|
| FilmMode | `0x0600` | Базовая имитация Classic Chrome по [таблице ExifTool FujiFilm](https://exiftool.org/TagNames/FujiFilm.html). |
| WhiteBalance | `0x0100` | В таблице ExifTool — Daylight. |
| WhiteBalanceFineTune | `[0, -80]` | Сырая пара. Документация ExifTool отмечает, что в новых камерах значения следует делить на 20; фактическое соответствие осям и экранным делениям X-H2 в этом опыте не подтверждалось. |
| Saturation | `0` | Таблица ExifTool обозначает normal/0; это один параметр, не весь рецепт. |
| HighlightTone / ShadowTone | `0` / `0` | Записанные числовые поля; в таблице ExifTool нуль соответствует 0. |
| Clarity | `0` | Записанное числовое поле; в таблице ExifTool нуль соответствует 0. |
| Sharpness | `3` | В таблице ExifTool — normal/0. |
| NoiseReduction | `0` | В таблице ExifTool для тега `0x100e` — normal/0. |
| ColorChromeEffect | `0` | Off согласно таблице ExifTool. |
| ColorChromeFXBlue | `32` | Weak согласно таблице ExifTool. |
| GrainEffectRoughness / Size | `0` / `0` | Off согласно таблице ExifTool. |
| DynamicRangeSetting | `1` | В таблице ExifTool обозначено Manual; само это число не устанавливает выбранный процент DR. |
| ColorTemperature | нет значения | Не восстановлено из этого тега. |

Это наблюдение **именно о выбранных записанных полях**, а не полный экспорт настроек камеры, не идентификатор C-слота и не доказательство фактических регулировок Lightroom. Совпадение этих полей не опровергает слова владельца о пользовательском рецепте: настройки вне набора тегов или сохранённая конфигурация могут отличаться; также не доказано, что все настройки однозначно и полностью представлены в доступном MakerNote. Для DSCF0001.RAF и DSCF9768.RAF основные значения дополнительно независимо прочитаны ExifRead. Ни один снимок не записывался или не модифицировался.

В 518 парных RAF/JPEG выбранные теги рецепта не различались; с учётом сообщения владельца это **совпадение сохранённых метаданных**, а не два независимых доказательства изображения из камеры. 10 JPEG без локального RAF оценить таким сравнением невозможно. Исходные данные и пофайловые значения: Каталог_снимков.tsv *(файл не публикуется)*, [Итоги.json](Итоги.json).

## Следствие для исследования прошивки

Для сравнения нужно держать раздельно:

1. базовую имитацию в данных камеры;
2. остальные настройки пользовательского рецепта и условия съёмки;
3. сырой сигнал RAW;
4. предпросмотр, встроенный в RAF;
5. фактический JPEG после Lightroom и его настройки проявки.

Ранее исследованная прошивочная ветвь Classic Chrome и четырёх коэффициентов — **только один компонент** потенциального рецепта. Ни совпадение имени `Classic Chrome`, ни четыре коэффициента не характеризуют пользовательский рецепт целиком. JPEG из этой папки нельзя использовать как эталонный SOOC-вывод X-H2 для проверки модели прошивки или как контроль сравнения фирменных симуляций. Это остаются полезные примеры для метаданных и данных сенсора, а JPEG — примеры итоговой пользовательской обработки Lightroom.

Для двух образцов `DSCF0001` и `DSCF9768` прочитанные встроенные предпросмотры имеют размер 4416×2944, отдельные Lightroom JPEG — 7728×5152. У всех четырёх файлов поле EXIF Software содержит `Digital Camera X-H2 Ver5.30`, что на конкретных данных показывает: эту строку нельзя использовать как доказательство происхождения JPEG. Источник встроенного изображения и совпадение цвета с гипотетическим SOOC-JPEG нуждаются в дополнительной проверке; не считаем их автоматически равными.

Для контролируемой проверки именно фирменного пути обработки нужен один и тот же RAF и два результата **камерной** RAW-конверсии с явно записанным полным набором настроек, меняя только выбранный фактор. Находящиеся здесь JPEG Lightroom годятся для исследования пользовательского результата, но не заменяют такие эталоны.

## Воспроизведение

`python -X utf8 Анализ_прошивки/Снимки_владельца/исследовать_снимки.py` повторно читает RAF-предпросмотры и JPEG, сохраняет сводку/каталог без GPS и серийных номеров; источники открываются только для чтения. `проверить_образцы.py` использует независимый ExifRead и rawpy для выбранных файлов. Группировка — по выбранным полям, не идентификация полных рецептов.
