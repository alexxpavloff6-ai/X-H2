## Результат A: сочетания настроек на DSCF0296

Полные JPEG проанализированы без масштабирования в кодовых 8-битных RGB; для компактного сравнения использована яркостная компонента `Y′=0,2126R′+0,7152G′+0,0722B′`, уровни 0–255. Это не линейная физическая яркость и не шкала L* из раздела B.

| Совместное изменение | Знаковый средний остаток по всему кадру, Y′ | Наблюдение |
|---|---:|---|
| Света 0 + тени 0 | −0,001 | Средние одиночные эффекты почти компенсируются; средний остаток близок к нулю. |
| Color 0 + Color Chrome Off | −0,183 | Совместная проявка отличается от суммы средних одиночных изменений. |
| WB 5000 K + Color Chrome Off | **−0,848** | Наибольший средний остаток из пяти пар; в средних тонах −1,278 Y′. |
| Clarity 0 + резкость 0 | +0,002 | Средний знаковый остаток близок к нулю; локальные отличия остаются. |
| Резкость 0 + HIGH ISO NR 0 | −0,002 | Средний знаковый остаток близок к нулю; локальные отличия остаются. |

Повтор A0 относительно 0300 имеет среднюю абсолютную разницу 0,841 уровня на компонент RGB, максимум 9 уровней и почти нулевую среднюю знаковую разницу Y′. Он подтверждает неидентичность повторных сохранений, но один повтор недостаточен для оценки разброса всех четырёх членов каждого контраста. На основании малого среднего остатка нельзя утверждать отсутствие локального взаимодействия; ненулевой остаток нельзя считать доказательством непосредственной связи внутренних блоков.

## Результат B: на чём виден FX Blue

На фиксированной синей маске (оттенок 210–310°, C*≥15, 15<L*<85; 47,9% точек сетки по B1) включение FX Blue Strong по сравнению с Off уменьшило среднюю светлоту на **4,896 L*** при включённом Color Chrome и на **4,897 L*** при выключенном. На тёплой маске парное действие FX Blue по средней попиксельной ΔE76 (1,065) сопоставимо с повтором B5–B1 (1,064). На этой тёплой маске включение Color Chrome снизило среднюю светлоту на 1,297 L*. Действие Color Chrome на выбранной синей маске по средней ΔE76 также сопоставимо с повтором. Указанные значения относятся к данному кадру Reala ACE и маскам, не ко всем объектам соответствующего цвета.

На той же синей маске FX Blue Strong увеличил среднюю цветность C* на **0,549** при Chrome Strong и на **0,545** при Chrome Off. Это небольшое изменение координаты Lab, а не процент насыщенности. На тёплой маске Color Chrome Strong увеличил C* на 0,205 при FX Strong и на 0,186 при FX Off.

Две оценки снижения средней L* синих областей от FX Blue почти совпали при обоих состояниях Color Chrome. Знаковый средний остаток взаимодействия в синей маске — примерно `(0,001; 0,001; −0,004)` в Lab; положительная средняя норма попиксельного остатка 1,427 не является статистическим доказательством взаимодействия: остаток включает четыре сохранения, а имеющийся повтор — только два. Это не доказывает ни наличие, ни полное отсутствие внутренней связи блоков.

## Как трактовать опыт

Для группы A сравниваются новые парные изменения, исходная проявка `0300` и уже имеющиеся соответствующие одиночные изменения. Для группы B составлена факторная схема 2×2 с повтором Strong/Strong. Формула остатка: `f(оба изменения) − f(первое) − f(второе) + f(база)`. Результат зависит от метрики и цветового пространства и описывает готовые JPEG данной сцены, а не обязательно непосредственную связь или порядок обработки внутренних блоков. Один повтор базы не устанавливает распределение ошибок каждого из четырёх JPEG и не превращает пиксели в независимые фотосъёмки.

Результаты и ограничения отдельных направлений: [группа A](Группа_A/Отчёт.md), [группа B](Группа_B/Отчёт.md). Метаданные, исполнение кода и пиксельные сравнения — разные уровни свидетельств. Совпадение или различие в одной камере не устанавливает то же самое для X-H2S, X-T5 и X100VI.
