# Итог: подсистемы за записями и путь к автофокусу X-H2 5.30 (18.11.2026, пятый круг)

Координатор — Claude Opus 5.5; исполнители Codex gpt-6-luna (xhigh): V1 записи, V2 настройки AF, V3 объектив (+ второй заход V4 lenscom). Камера не использовалась.

## Главное

1. **Метки подсистем у записей хранилища (Д, V1):** `0x88` — поток **lenscom** (регистратор `0x13E6420`, обработчик `0x13EB4DC`, 48 × 0x48), `0x8B` — **biscom** (`0x13FCAB0`), `0x03` — **reccont** (инициализатор `0x2D5A998`, цикл `0x2D67134`), `0x4F` — очередь событий блока 0 (`0x1576AA8`, читатель `0x15669E0`), `0x02` — 0x1D0 байт, район съёмочного тракта (`0x2E89120`), читатель не найден.
2. **lenscom (V4, Д):** поток сам читает `0x88` (`0x14CF354`, буфер `0x22743B0`), классифицирует коды `0x18D9–0x1944` (`0x13E5408`), ветвится по таблице `0x1912414` (`0x13EBB88`); 112 кодировщиков сведены в таблицу. Явных команд «двигать фокус / стоп / скорость / положение» не найдено (кандидаты телеметрии — `0x1909`, `0x1914–0x1919`). Публикации уходят в службы загрузчика (`0x50468`, `0x51640`, `0x5460C`); физический транспорт к объективу не виден. biscom устроен так же; ветка `0x19B5` распаковывает знаковое 12-битное значение — совместимо со стабилизатором, не доказано (Г).
3. **Ручной фокус (V3, Д):** диспетчер операций объектива `0x2CEB0E4` (вызывающие `0x2CE7C50`, `0x2DEA008`, `0x2DF0A30`); MF-операции `0x1E/0x20` с параметрами `0x1DB3` (шаг) и `0x1DBA` (16-битное значение) → поля выходной структуры `+0x50`/`+0xA0`. Прямых обращений к регистрам интерфейса крепления в блоках 0–2 нет; с lenscom не связан.
4. **Настройки AF (V2, Д):** пакетного снимка настроек AF нет; копирования `0x618/0x620/0x624` в `0x2BD5114` — это поля верхнего дисплея; сборка строки AF-C `0x2BF8784/0x2BF8848` — USB-ответ (D233).
5. **Граница (Г, по совокупности):** алгоритм автофокуса и физический обмен с объективом лежат вне блоков 0–2. Ни сеттер, ни хранилище записей, ни lenscom не доводят настройки AF до команд объективу. Ядро M4 маловероятно (нет последовательного интерфейса, его mailbox в блоках 0–2 не читается). Наиболее вероятное место — зашифрованный блок `0x2300274` (1.53 МБ) или отдельные вычислительные ядра процессора со своей прошивкой. Пересечь границу статикой нельзя: нужна трассировка на камере (перехват `0x14CF124`/шины `0x12E863C`/служб загрузчика) или ключ к зашифрованному блоку.

## Что это даёт для доработок

- Для доработок, связанных с объективом, точка входа на стороне A53 — поток lenscom (`0x13EB4DC`) и его таблица кодов, а для ручного фокуса — диспетчер `0x2CEB0E4`. Логику AF через них не поменять: она за границей.
- Настройки фокуса, которые можно менять «снаружи» (меню, USB), полностью описаны картой сеттера; их влияние на работу AF проверяется только опытами на камере.
