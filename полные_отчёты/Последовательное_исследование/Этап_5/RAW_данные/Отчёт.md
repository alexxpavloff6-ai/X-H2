# Проверка сенсорного массива DSCF0296.RAF

## Результат

Для **одного конкретного несжатого файла** `DSCF0296.RAF` целиком сверены данные указанной метаданными области `FujiIFD:StripOffsets/StripByteCounts` с массивом `raw_image`, декодированным rawpy 0.27.1 / LibRaw. Все **40 902 912** 16-битных значений совпали при чтении исходных байтов в порядке little-endian; несовпадений **0**. Это не демозаика, не JPEG и не измерение того, как прошивка записывала файл.

## Проверенные числа

| Поле | Значение |
|---|---:|
| Размер полного массива | 7872 × 5196 отсчётов |
| Смещение начала strip от начала RAF | 3 505 152 байта |
| Размер strip | 81 805 824 байта = 7872 × 5196 × 2 |
| Указанная глубина | 14 бит на отсчёт |
| Отсчёты больше 16 383 | 0 |
| Расхождения при little-endian против LibRaw | 0 |
| Расхождения при big-endian против LibRaw, отрицательный контроль | 40 074 178 |

Длина, отсутствие расхождений и отрицательный контроль подтверждают представление этого массива как последовательных 16-битных little-endian чисел на проверенном файле. Это не доказывает такого же формата для всех камер Fuji, RAW с lossless/lossy-сжатием или будущих версий. Совпадение с LibRaw — сравнение с конкретным декодером, а не независимая аппаратная калибровка. Массив включает области по краям, а не только видимую область фотографии; не все значения являются конечными пикселями. Данные баланса белого и других настроек не применялись.

## Воспроизведение и границы

Сначала нужны ранее извлечённые метаданные `Проявка_0296/Метаданные/метаданные.json`; сценарий сверяет хеш RAF с указанным там хешем. Из корня проекта: `python -X utf8 Анализ_прошивки/Последовательное_исследование/Этап_5/RAW_данные/проверить.py`. Требуются NumPy и rawpy. Сравнение идёт полосами без сохранения изображения; [результат.json](результат.json) содержит только агрегаты, версии и SHA-256 файла до и после, совпавшие во время опыта.

Важная граница: выяснено представление данных готового файла, но **не прослежен весь путь матрица → буферы → кодировщик → файловая система → карта** и не доказано, какая конкретно функция прошивки записала эту область.
