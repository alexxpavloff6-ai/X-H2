# Представление параметра «Цвет» в четырёх прошивках

## Результат

В каждой прошивке найдена и отдельно исполнена собственная функция, сопоставимая с X-H2 `0x02e51064`. При одинаковых искусственных значениях контекста 2, режима 19 и внутреннего значения цвета 0…8 все четыре функции вернули один и тот же ряд `0x00e0, 0x00c0, 0x0100, 0x0080, 0x0000, 0x0180, 0x0400, 0x04c0, 0x04e0`. В интерпретации тега Saturation по ExifTool это значения от +4 до −4.

Для X-H2 дополнительно исполнены исходный вызывающий участок, запись результата в структуру и при искусственном повторном использовании структуры построитель записи MakerNote. Для остальных трёх здесь исполнялись **только функции преобразования**, без их вызывающих и сериализации. Режим 19 и поле цвета исследователь задавал в RAM вручную. Это не непрерывная съёмка, не доказательство одинакового происхождения входа и не сравнение пикселей или цвета реальных фотографий.

| Модель | Адрес функции | Поля контекста / режима / цвета |
|---|---|---|
| X-H2 5.30 | `0x02e51064` | `+0x3978 / +0x39b8 / +0x39b4` |
| X-H2S 7.30 | `0x03168340` | `+0x391c / +0x395c / +0x3958` |
| X-T5 4.31 | `0x02d8f19c` | `+0x39c0 / +0x3a00 / +0x39fc` |
| X100VI 1.31 | `0x0305f144` | `+0x3fa8 / +0x3fe8 / +0x3fe4` |

Адреса виртуальные в распакованных моделях, а не адреса работающих камер или смещения DAT. Функции сопоставлены по потоку инструкций и набору условных констант; оригинальные машинные инструкции каждой модели исполнены отдельно.

## Преобразование имитации

Отдельно на каждой модели выполнена собственная функция представления имитации при искусственном контексте 2. Для входов `0, 4, 13, 19, 22` все четыре вернули соответственно `0x0000, 0xffff, 0x0600, 0x0800, 0x0b00`. Адреса функций: X-H2 `0x02e516fc`, X-H2S `0x031689e4`, X-T5 `0x02d8f8b4`, X100VI `0x0305f888`. Только для X-H2 отдельно выполнены запись выходного значения и построитель тега FilmMode. Значения `0x0600`, `0x0800`, `0x0b00` совпадают с наблюдёнными тегами Classic Chrome, Classic Negative и Reala ACE в JPEG X-H2, но опыт не доказывает запись тега тремя другими моделями и не использует их реальные фотографии.

## Контроли

Для всех четырёх при контексте 2, режиме 4 и цвете 3 возвращается `0x0300` вместо `0x0080`; при контексте 46, режиме 19 и цвете 3 — `0xffff`; при контексте 2, режиме 19 и искусственном значении цвета 9 — 0. Значит, результат не определяется одним значением цвета; выход 0 для недокументированного входа не подтверждает возможность выбрать этот вход в меню.

## Проверка и границы

Из корня проекта: `python -X utf8 Анализ_прошивки/Последовательное_исследование/Этап_1/Цвет_четырёх_камер/исследовать.py`. Программа распаковывает каждый предоставленный DAT, проверяет его SHA-256 до и после, выполняет функции в Unicorn и сохраняет [результаты.json](результаты.json) только в своём каталоге. Нужны Python, Unicorn, Capstone и проектный распаковщик.

[Прямые байты тестовой серии X-H2](../Байты_MakerNote/Отчёт.md), [детальное преобразование X-H2](../Цвет_в_MakerNote/Отчёт.md), [построитель MakerNote X-H2](../MakerNote/Отчёт.md). Реальных тестовых файлов с других моделей этот опыт не использует.
