# Доступность сравнений по DSCF0296.RAF

## Итог

Для одного и того же RAW по сообщению владельца имеются три полноразмерные камерные проявки: **DSCF0300.JPG — Color +1, DSCF0301.JPG — 0, DSCF0302.JPG — +2**. Метаданные согласуются с этим, но не доказывают происхождение пикселей. Уже доступны три парных сопоставления Color: 0300–0301, 0300–0302 и 0301–0302. Это кандидаты для анализа влияния Color, а не доказательство отсутствия всех скрытых различий и не новые измерения изображения.

Для светов, теней, Color Chrome Effect, Color Chrome FX Blue, WB, clarity, sharpness и noise reduction **подходящих различающихся пар пока нет**: записанные значения для всех трёх JPEG одинаковы. Для исследования каждого из восьми параметров необходимо получить результат от владельца. Другие RAF, в том числе 0297, — другие съёмки; их JPEG нельзя считать проявками 0296 или изолированными изменениями рецепта. JPEG Lightroom не является прямой камерной проявкой. Встроенный JPEG RAF — уменьшенное превью, не полноразмерный камерный JPEG, и не служит базой сравнения.

## Матрица фактических значений

Здесь приведены отображаемые ExifTool 13.61 значения; полные выбранные числовые и отображаемые теги RAF и JPEG, все три пары и проверка равенства других полей матрицы — в [машинной матрице](матрица.json). `-n` означает ValueConv без PrintConv, а не обязательно исходные байты. В RAF метаданные JPEG/превью не следует приравнивать к отдельному полноразмерному JPEG.

| Параметр | 0296.RAF | 0300 | 0301 | 0302 | Сейчас |
|---|---|---|---|---|---|
| Color / Saturation | +1 | +1 | 0 | +2 | три JPEG-пары |
| Света / HighlightTone | +1,5 | +1,5 | +1,5 | +1,5 | различающейся пары нет |
| Тени / ShadowTone | +0,5 | +0,5 | +0,5 | +0,5 | нет |
| Color Chrome Effect | Strong | Strong | Strong | Strong | нет |
| Color Chrome FX Blue | Strong | Strong | Strong | Strong | нет |
| WB | Kelvin 5750 K; 20, −100 | то же | то же | то же | нет |
| Clarity | +3 | +3 | +3 | +3 | нет |
| Sharpness | −1 | −1 | −1 | −1 | нет |
| HIGH ISO NR / NoiseReduction | −4 | −4 | −4 | −4 | нет |

Пара WB — численное `WhiteBalanceFineTune`, не подтверждённые значения экрана. По правилу ExifTool для новых камер возможны шаги R+1/B−5, но экран X-H2 независимо не проверен; не вводить в камеру +20/−100 как шаги UI. В предыдущем [отчёте о метаданных](../../../Проявка_0296/Метаданные/Отчёт.md) среди сохранённых неприватных числовых тегов JPEG различались Saturation, ModifyDate и производная дата, а также длина миниатюры; это не гарантирует равенство неотображённых параметров. Совпадение настроек в таблице само по себе не устанавливает влияние на пиксели, а одинаковый записанный WB не является измерением цвета.

## Запрос владельцу: восемь вариантов и рекомендуемый контроль

Для одного контраста по каждому из восьми параметров достаточно восьми новых JPEG, если при проверке их настройки и формат сопоставимы с имеющимся `DSCF0300.JPG` (рецепт +1, FINE). **Девятая, повторная контрольная проявка рекомендуется**, чтобы проверить повторяемость и одинаковые условия новой серии; она не является строгим минимумом. Запись `NORMAL` в метаданных RAF относится к встроенному JPEG-превью, а не устанавливает, что соответствующий новый полноразмерный JPEG неизбежно должен быть NORMAL. Для расширения шкал и проверки повторяемости на разных сценах потребуются дополнительные данные.

**Общая процедура перед каждым из восьми вариантов и рекомендуемым контролем:**

1. Открыть на X-H2 исходный **DSCF0296.RAF**, не 0297 и не ранее сохранённый JPEG. В режиме просмотра нажать MENU/OK → RAW CONVERSION (либо Q на открытом RAW).
2. Выбрать **REFLECT SHOOTING COND.** — восстановить условия съёмки, а не настройки предыдущей конвертации. Проверить значения из таблицы, включая Color +1, Classic Negative и WB. Не пытаться вручную пересчитывать WB shift из чисел EXIF; записать фактически показанное экраном значение. Если после восстановления оно не совпадает между проявками, остановить серию и сообщить об этом.
3. Для **каждого** выхода установить одинаково FILE TYPE JPEG, IMAGE SIZE O 3:2 (7728×5152) и IMAGE QUALITY FINE. Это общие настройки формата, а не исследуемое изменение; при их отличии от восстановленных условий формально меняется и формат выхода. Все остальные настройки, включая WB shift, экспозицию PUSH/PULL, DR, фильм, зерно, LMO и цветовое пространство, оставить восстановленными и одинаковыми. Записать отображаемые значения и отметить недоступные или автоматически изменившиеся пункты; не исправлять их наугад.
4. Для рекомендуемого контроля не менять исследуемые параметры; для остальных проявок изменить **только** одну строку следующей таблицы. После изменения проверить, что остальные значения, особенно вторая половина TONE CURVE и WB shift, не изменились. Если камера автоматически меняет другой параметр или целевое значение недоступно, не объявлять такую пару однофакторной: зафиксировать это и пропустить вариант.
5. Нажать Q для превью, затем MENU/OK для сохранения копии. Записать соответствие фактического имени созданного файла строке таблицы и условиям. Вернуться именно к RAW и повторить все шаги, включая REFLECT SHOOTING COND., для следующей строки; имена файлов заранее не предполагать. Передать оригинальные JPEG без редактирования и таблицу соответствий, без GPS/серийных номеров в сопроводительном журнале.

| Метка журнала | Единственное исследуемое изменение относительно контроля | Для сравнения |
|---|---|---|
| base | нет; рекомендуемый повтор исходного рецепта | контроль всех восьми пар; имеющийся 0300 также остаётся кандидатом |
| highlight_0 | TONE CURVE: HIGHLIGHT +1,5 → 0; SHADOW оставить +0,5 | base |
| shadow_0 | TONE CURVE: SHADOW +0,5 → 0; HIGHLIGHT оставить +1,5 | base |
| chrome_off | COLOR CHROME EFFECT STRONG → OFF | base |
| blue_off | COLOR CHROME FX BLUE STRONG → OFF | base |
| wb_5000 | WHITE BALANCE / COLOR TEMPERATURE 5750 → 5000 K; режим Kelvin и восстановленный WB SHIFT оставить без изменения | base |
| clarity_0 | CLARITY +3 → 0 | base |
| sharpness_0 | SHARPNESS −1 → 0 | base |
| nr_0 | HIGH ISO NR −4 → 0 | base |

При изменении температуры WB повторно проверьте WB SHIFT: если камера сбросила или изменила его и сохранить исходное значение нельзя, эксперимент не изолирует температуру. Света и тени — две составляющие одного TONE CURVE, поэтому отдельно проверять неизменяемую составляющую. Перед выводами сверить переданные JPEG по метаданным и фактическому протоколу; отсутствие тега или внешнее подтверждение происхождения ограничивают уверенность. Запрос не утверждает, что эти файлы существуют или что их влияние измерено.

## Официальная доступность и ограничения

[Онлайн-мануал FUJIFILM X-H2, Playback → RAW CONVERSION](https://fujifilm-dsc.com/en-int/manual/x-h2/playback/menu_playback/index.html#raw_conversion) прямо перечисляет REFLECT SHOOTING COND., FILE TYPE, IMAGE SIZE, IMAGE QUALITY, COLOR CHROME EFFECT, COLOR CHROME FX BLUE, WHITE BALANCE, WB SHIFT, TONE CURVE (света и тени), COLOR, SHARPNESS, HIGH ISO NR и CLARITY. Он описывает Q для превью и MENU/OK для сохранения. Важная оговорка производителя: **некоторые настройки могут быть недоступны в зависимости от выбранных при съёмке опций**. Сам список не доказывает фактическую доступность каждого значения для данного RAF и версии прошивки; владелец должен проверить на камере. [Раздел IMAGE QUALITY SETTING](https://fujifilm-dsc.com/en-int/manual/x-h2/menu_shooting/image_quality_setting/index.html) документирует 3:2 7728×5152, уровни Strong/Off и диапазон температуры 2500–10000 K; он описывает меню съёмки и не заменяет проверку экрана RAW-конвертации. В нём также указано, что при HEIF отключается CLARITY; поэтому для протокола задан JPEG.

## Воспроизведение и целостность

Из корня проекта запустить `python Анализ_прошивки/Последовательное_исследование/Этап_2/Доступность_сравнений/матрица.py`. Python 3 использует только стандартную библиотеку. Сценарий повторно читает и хеширует всю фактически имеющуюся серию и ранее подготовленный JSON метаданных до и после, отказывается писать результат при изменении или изменении состава, сверяет SHA-256 четырёх основных файлов с сохранёнными в результатах метаданных, строит матрицу из выбранных полей и записывает только `матрица.json` рядом с собой. Хеши до/после — внутри JSON; это проверка интервала выполнения, а не всей истории файлов. Существующие результаты извлечены ExifTool 13.61; этот сценарий **не извлекает метаданные заново**. Для пересоздания исходных метаданных см. связанный предыдущий отчёт. Исходники и изображения не записываются, GPS и серийные номера в результаты не переносятся. Сравнение опирается на сообщение владельца о связи файлов и записанные теги; скрытые установки и происхождение пикселей независимо не удостоверены.
